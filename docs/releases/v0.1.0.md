OpenCode Sidebar 0.1.0 brings the official OpenCode Solid UI into the VS Code sidebar.

- Connect to an existing local shared OpenCode service, or start it when needed.
- Respect `service disabled` and reuse the existing service when versions differ.
- Attach the active file or selection, including unsaved editor content.
- Review the session's file changes in VS Code's native diff editor.
- Reuse OpenCode's sessions, models, tool activity, permission prompts and question forms.
- Preserve unsent drafts and attachments across reconnects and window reloads.

**Install:** Download `opencode-sidebar-0.1.0.vsix`, select **Extensions → Install from VSIX…**, then run **OpenCode: Open Sidebar**.

Requirements: VS Code 1.94 or later and a locally installed OpenCode CLI. The bundled UI is pinned to OpenCode 2.1.2.

Validation includes lint, typecheck, adapter tests, isolated shared-service startup, UI fixtures, and installation in a real VS Code extension host on Windows. Linux and macOS runtime use has not been manually verified. Remote SSH and WSL remote workspaces are outside this first release.

This is a community extension maintained by HunkYuan. It reuses the official UI under its MIT license and is not an official OpenCode extension.
