OpenCode Sidebar 0.2.0 separates the VS Code extension Host from the official OpenCode UI.

- UI packages include the official Solid UI, matching Client SDK, VS Code Composer adapters, static assets and licenses.
- The extension checks its UI catalog automatically, downloads compatible packages, verifies their SHA256 and uses them when the sidebar is next recreated.
- The first installation includes a verified UI. Failed downloads keep the current package; startup failure falls back to a previous package.
- **Check UI Updates**, **Apply UI Update** and **Roll Back UI** provide manual controls. Applying an update saves drafts first and waits until active work finishes.
- Native diff requests now run through the UI's matching SDK; the Host validates the resulting patches and opens VS Code's diff editor.
- The upstream workflow monitors official GitHub and npm stable releases every six hours. It validates the same fixed source on Windows and Linux, automatically merges a successful candidate, publishes a UI ZIP, verifies its public download and then updates the catalog.

**Install:** download `opencode-sidebar-0.2.0.vsix`, select **Extensions → Install from VSIX…**, then run **Developer: Reload Window**. Future compatible UI updates do not require reinstalling the VSIX.

Requirements: VS Code 1.94+ and a locally installed OpenCode CLI. OpenCode service itself follows your existing upgrade method; the extension does not replace your running service.

The initial bundled UI uses the validated OpenCode baseline; OpenCode 2.1.4 is available through the independent UI catalog. Each downloaded UI package declares the service versions verified against it. A newly published OpenCode version is added only after its fixed source, build and compatibility tests pass.

Local validation covers lint/typecheck, 13 adapter and package tests, actual attachment sends, update and rollback with drafts, session/Markdown/permission/form fixtures and real VS Code 1.94. The editor verification includes saved GBK text, unsaved selection, file links, native diff, and successful sending after applying or rolling back a UI package.

Linux and macOS editor use still requires manual verification. Remote SSH and WSL remote workspaces remain outside the supported scope. Please verify the update in your own project.
