OpenCode Sidebar 0.3.0 uses source distribution and locally built UI packages.

Build the extension with `bun run setup`, `bun install --frozen-lockfile`, `bun run check`, `bun test ./test` and `bun run package`. Install the resulting VSIX from the local repository directory.

To update only the UI, run `bun run ui:upstream <OpenCode-version>` and `bun run build:ui`, then use **OpenCode: Import UI Package** to select the local ZIP. The import verifies every file, host protocol and service compatibility before caching it. **Apply UI Update** saves drafts before loading the package; **Roll Back UI** restores a previous compatible version.

GitHub Actions and hosted build assets are retired. The extension no longer reads an online update catalog or requires a GitHub token. The local version preparation command updates pinned source/dependencies without making a commit, PR or push.

The existing service discovery, editor snapshots, GBK support, file links, native diff, working-directory storage and Host protocol remain. Old cached state can be read without contacting its retired catalog. Old ZIPs without an integrity manifest must be rebuilt.

Validation covers local source preparation, fourteen unit/contract tests, UI packaging, actual GBK/UTF-8/unsaved/selection sends, draft reloads, permissions/forms and real VS Code 1.94 local import/application/rollback.

This file is a source changelog, not a hosted release. Build tools are needed only during local compilation. Please verify the update in your daily project; Linux/macOS editor use still requires manual verification.
